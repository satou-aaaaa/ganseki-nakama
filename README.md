# 岩石なかま分け（ganseki-nakama）

岩石のでき方や、もとになったものの説明を読んで、岩石の名前を当てる1日5問の学習ゲーム。正解したら、その岩石のなかま（火成岩・堆積岩・変成岩）も選ぶ。中学理科「大地の成り立ちと変化」の岩石。

遊ぶ: <https://satou-aaaaa.github.io/ganseki-nakama/>

- 中身は産業技術総合研究所 地質調査総合センターの「岩石の分類」（<https://www.gsj.jp/geology/fault-fold/formation/r-classification/index.html>）・「岩石や地層のでき方」（<https://www.gsj.jp/geology/fault-fold/formation/index.html>）・「日本の火山とマグマ」（<https://www.gsj.jp/geology/geology-japan/geology-volcano/index.html>）に書いてあることだけです。
- 説明は解説を短く言いかえたものです。岩石は天然のものなので、分け方の決まりにいつもぴったり当てはまるわけではありません。このゲームは鑑定の代わりではありません。
- 火砕岩（凝灰岩など）は、火成岩とも堆積岩とも分けられるので出していません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
